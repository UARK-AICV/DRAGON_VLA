## Abstract

<div class="text-justify space-y-4">

Vision–Language–Action (VLA) models adapt pretrained Vision–Language Models (VLMs) for robotic control, yet often fail to bind instructions to the correct visual evidence. Our single-object sanity check shows that state-of-the-art policies frequently grasp the visible object when the requested referent is absent. We ask whether explicit grounding can improve instruction–scene alignment under visual distraction and distribution shift without distractor-rich demonstrations or auxiliary perceptual objectives.

We propose *Distraction-Robust Action via Geometric and Object-ceNtric Grounding* (DRAGON-VLA), an integrated perception–control system. Its two-stage object-centric module uses an off-the-shelf VLM to select task-relevant segmentation proposals in a base view and semantically match the same objects in a wrist view. A geometric module converts the selected regions into masked monocular relative-depth observations that preserve shape and spatial layout while suppressing appearance, background, and distractors. These grounded multi-view inputs condition a pretrained VLA fine-tuned only on clean, single-object demonstrations. DRAGON-VLA thus provides a task-aware, calibration-free interface combining base-view anchoring, semantic cross-view matching, and explicit depth grounding without additional high-level grounding supervision.

On a real-world UR10e tabletop setup, DRAGON-VLA outperforms strong VLA baselines under competing distractors, absent referents requiring abstention, background shifts, and held-out object categories. With seven distractors, the grounded policies retain around 80% task success while the baselines fall below 10%; they also achieve approximately 95% absent-target rejection. Ablations show that object-centric filtering accounts for the largest gains, while masked relative-depth inputs provide their clearest additional benefit on unseen objects. These results support explicit perception grounding as an effective systems intervention for referentially reliable VLA manipulation. Physical clutter requiring obstacle-aware motion and interaction remains outside scope.

</div>

## Approach

<Figure>
  <Picture
    slot="figure"
    src="../assets/architecture.pdf"
    alt="DRAGON-VLA architecture showing perception grounding and action policy."
  />
</Figure>

<div class="text-justify space-y-4">
DRAGON-VLA takes synchronized base- and wrist-view RGB observations and first uses a real-time segmentation model to generate object-mask proposals. Given the instruction, an off-the-shelf VLM selects task-relevant proposals in the base view and semantically matches the same objects in the wrist view using base-view reference crops. The selected masks suppress irrelevant regions in both views. A geometric grounding module then applies these masks to monocular relative-depth estimates, producing task-conditioned observations that preserve object shape and spatial layout while reducing appearance, background, and distractor cues. These grounded observations, together with the instruction and robot proprioception, condition a pretrained VLA fine-tuned only on clean, single-object demonstrations. The perception grounding module remains frozen, and the interface does not require camera calibration.

</div>
